# 1 大圆联动：消息的读取、检索和发送，由大圆承接

> ⚠️ **先知道再使用**：大圆是企微里**权限特别高的 AI 入口**——能读你的聊天记录和邮件、按群按时间段检索消息、还能以你的名义发消息。用法本篇讲；**它能出什么事见 [[02-大圆维度/02-大圆风险清单-能读消息能代发十一条要防|02篇：风险清单]]，公司和个人的管理动作见 [[02-大圆维度/03-大圆怎么管-范围最小敏感群禁用月审|03篇：怎么管]]。**

**结论**：「大圆」是企业微信**内置的原生 AI 智能助理**（企微 5.0.9 上线、截至 2026-11 仍属内测灰度；手机"贴边把手"、电脑快捷键随时唤起）。它**本身就是全能助理**——总结聊天、读写文档表格、汇总项目进展、设置定时任务、联网搜索都行；在与 WorkBuddy 联动时，**聊天消息的读取、检索和发送由大圆承接**，文档、日程等业务数据走 wecom-unified 连接能力（见[[01-WorkBuddy维度/04-session直连企微连接器-会话内编辑文档表格|WorkBuddy篇：session直连连接器]]）。⚠️ 它没有企业管理后台（管理现状见 [[02-大圆维度/03-大圆怎么管-范围最小敏感群禁用月审|03篇：怎么管]]）。

## 一、大圆能替你干什么（消息类）

| 动作 | 具体能力 | 铁规矩 |
| :--- | :--- | :--- |
| **整理未读** | 未读消息和邮件分类：**需处理 / 值得关注 / 其他**， 逐条提炼重点、梳理待办 | 读你的会议内容、邮件等敏感操作**需员工本人授权** |
| **总结群聊** | 按指定群聊 + 时间范围总结；自动识别聊天中引用的**在线文档、微盘文件、日程、会议纪要**并读取原文 | 让 WorkBuddy 调用大圆按群和时间范围检索，材料指清楚 |
| **检索消息** | 在指定群聊、指定时间段里找某条消息/某个话题 | 范围说清楚（哪个群、哪几天），别让 AI 全公司翻 |
| **代发消息** | 以你的名义向同事或群聊发送文本、链接和文件 | **发送前必须手动确认接收对象和具体内容**，没有全自动代发 |

**提示词范本**（照这个结构写）：

> 总结一下"客服一群"今天关于 XX 项目的讨论重点，引用到的文档帮我读一下原文，最后列三条待办。

> 把我未读邮件分成"需要我回复"和"只需知悉"两类，每封一句话；需要回复的帮我起草，**不要直接发**。

## 二、消息怎么喂给 WorkBuddy：直接转发

企微里的聊天记录可以**直接转发到 WorkBuddy**：选中聊天记录 → 转发 → 更多 → WorkBuddy，记录以压缩文件形式进入会话。5.5.5 起，转发记录里夹带的**文档、微盘文件、日程、待办、会议、智能纪要会被自动解析**，不用一个个另存再上传。

三条注意：

1. **附件不会自动发送**——转发后先核对范围再让 AI 处理；
2. 高频转发会遇到**频控提示**，按提示等待，别反复点；
3. 解析失败的附件保留提示即可，**不要把未解析内容当作已读**。

## 三、两条铁律（安全底线）

1. **本人授权不可绕过**：会议内容、邮件读取等敏感操作需员工**本人授权**，**管理员也无法绕过员工授权**访问这类内容（凤凰网 2026-10-14 报道确认）；
2. **代发必须本人确认**：发送前逐条核对**接收对象 + 具体内容**。让 AI 起草可以，让 AI 直接发——平台不允许，我们也别用任何变通办法绕。

## 四、大圆 vs 通讯录机器人 vs session，怎么选

| 需求 | 用哪个 |
| :--- | :--- |
| 整理消息/邮件、总结群聊、代发 | 大圆联动（本篇） |
| 日常问答、群里 @ 派活 | [[03-企微bot维度/01-通讯录机器人-WorkBuddy在企微里的分身\|bot篇：通讯录机器人]] |
| 改文档、写表格、做 PPT、跑自动化 | [[01-WorkBuddy维度/04-session直连企微连接器-会话内编辑文档表格\|WorkBuddy篇：session直连连接器]] 或客户端 |

三者在企微端内上下文**双端同步**，切换使用不必重复说明背景。

## 五、常见卡点

- **大圆里关联不上 WorkBuddy 机器人** → 先确认：企业已认证、双端版本达标（[[01-WorkBuddy维度/02-开通条件与领取席位|WorkBuddy篇：开通与领席位]]）、你的席位已领取、机器人对你可见；
- **总结出来的群聊内容不对** → 检查群名和时间范围是否说清楚了；AI 不默认读取 @ 之前的全部群聊；
- **代发点了发送没反应** → 检查是否漏了本人确认步骤；这是平台设计不是故障。
