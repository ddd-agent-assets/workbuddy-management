# 3 大圆怎么管：企业侧没有后台，就靠"两个硬抓手 + 三块个人看板巡检 + 制度补位"

**结论**：先把产品现实说透——**大圆没有企业管理后台**。截至 2026-11（企微 5.0.12，大圆 5.0.9 上线、仍属内测灰度），官方《智能助理个人信息处理规则》里企业管理员唯一能设的是**云端消息保存期限**（任务输入与执行结果存多久）；定时任务看板、最近任务列表、隐私开关、风险确认**全在个人侧**。所以管大圆的务实打法是三件套：**①用仅有的两个硬抓手（企微侧权限总闸 + 云端保存期限）；②把个人侧三块看板变成巡检项和台账项**（管理员看不到的，让使用者定期申报）；③制度只补产品覆盖不到的缝。风险条目见 [[02-大圆维度/02-大圆风险清单-能读消息能代发十一条要防|02篇：风险清单]]。

## 一、产品现实：大圆的管理面长什么样（2026-11 核查）

| 管理面 | 在哪 | 谁能操作 | 性质 |
| :--- | :--- | :--- | :--- |
| **云端保存期限** | 企微管理后台（大圆相关设置） | **企业管理员——大圆唯一的企业级控点** | 硬 |
| **企业应用权限总闸**（间接） | 企微管理后台 → WorkBuddy → 允许的权限（[[05-公司管理流程/01-管理员两个后台-企微管理端加WorkBuddy后台\|管理控制点全景]]①） | 管理员 | 硬（限的是大圆联动 WorkBuddy 时能用什么能力） |
| **定时任务看板** | 智能助理首页 → 定时任务：**立即运行 / 暂停 / 删除** | 员工本人 | 个人侧看板 |
| **最近任务列表** | 智能助理 → 最近任务：查历史任务、**删除（含云端保存的文件产物）** | 员工本人 | 个人侧看板 |
| **数据隐私与安全开关** | 一周小结首页 → 数据隐私与安全 → AI 一周小结开关 | 员工本人 | 个人侧看板 |
| **风险操作确认** | 扩大权限/风险操作时弹确认（允许/拒绝） | 员工本人 | 平台防线 |
| ⚠️ **完全访问权限开关** | 助理设置内：开启后**不受限制读写任意文件、运行命令、安装软件、改系统设置**，官方标注"风险自负" | 员工本人 | **高危，公司一律禁开** |

> 记住这个不对称：**大圆的能力是企业级的（读写文档表格、定时任务、联网搜索、消息收发），管控却是个人的**。管理的核心思路就是把"个人侧看板"变成"组织可见的巡检项"。

## 二、硬抓手一：企微侧权限总闸（限能力，不是限大圆本身）

大圆联动 WorkBuddy 机器人时，能调什么能力受企微管理后台"**允许的权限**"控制——不授权的能力，成员在 WorkBuddy 机器人里就用不了。因此：

- 按**最小化**开权限：用不到"微盘""会议"的场景就不开对应权限（[[05-公司管理流程/01-管理员两个后台-企微管理端加WorkBuddy后台|控制点①]]）；
- 敏感场景收紧：涉及敏感数据分级的场景，对应能力（邮件、会议、微盘）不开或逐场景开；
- 这是**间接控制**——它限的是"联动后的能力面"，不限大圆原生功能（总结聊天、读有权限的文档）。

## 三、硬抓手二：云端保存期限（限留存）

- 管理员在企微侧设定任务输入与执行结果的云端保存期限——**按公司数据留存政策设短**（如 30 天），降低 R8（总结产物二次传播）与 R9（账号失窃）的暴露面；
- 注意例外：任务过程中处理的原始信息官方声明"不额外保存"，本地文件内容不上云；跨设备查看需要的产物会存云、可手动删——**离职交接时"最近任务列表清空"要进动作清单**（见第六节）。

## 四、个人侧看板 → 巡检项：管理员看不到的，怎么变成组织可见

三个动作，把三块个人看板挂进管理流程：

| 看板 | 巡检动作 | 频率 | 落到哪 |
| :--- | :--- | :--- | :--- |
| **定时任务看板** | 使用者申报在跑的大圆定时任务清单（名称、频率、指令摘要），新任务上线前报备 | 上线报备 + **季度申报** | 台账"大圆关联"字段（[[05-公司管理流程/03-登记台账-在线表格\|登记台账]]） |
| **最近任务列表** | 离职/调岗时**清空最近任务**（含云端产物）；敏感场景任务用完即删 | 交接时 + 高敏场景即用即删 | [[05-公司管理流程/08-调岗离职交接-先停写再验证七天收权\|交接篇]]大圆专项 |
| **隐私开关与完全访问权限** | 两条红线：**"完全访问权限"一律禁开**（开了=本地文件全暴露，见风险 R11）；"保持电脑唤醒"远程开关离开工位即关 | 纳入 IT 季度安全巡检的自查项 | 部门负责人确认 |

> **为什么能这么做**：大圆个人侧的看板虽不在企业后台，但入口和操作都标准化（首页 → 定时任务/最近任务），申报成本低；把"申报+抽查"写进制度，就把不可见变成半可见。管理员抽查时让对方**当面打开**定时任务看板核对，不用截图存证（截图本身也是敏感材料）。

## 五、制度补位：只补产品覆盖不到的三条缝

1. **敏感群清单**（OD+数据负责人维护）：薪酬/涉密/客户核心资料群禁用 AI 整理——平台不管群内容分级，只有我们管；季度复核；
2. **检索范围最小化 + 确认三看**（写进使用规范）：点名群+时间段；代发确认看对象/正文/群——平台有确认机制，但"看不看内容"只能靠规范；
3. **总结当草稿**：AI 产出只作草稿，对外使用前人工核对——频控/解析失败会产生"没读全就总结"的错误结论。

## 六、调岗离职：大圆专项四步

1. **停**：定时任务看板逐个**暂停/删除**在跑任务；
2. **清**：最近任务列表**删除**（含云端保存的文件产物）；
3. **解**：解除大圆与 WorkBuddy 机器人的关联；关闭"保持电脑唤醒"远程开关；
4. **交**：接手人按需重建任务、重新关联，涉敏感群的场景**重新过上线检查**（[[05-公司管理流程/02-上线检查清单-打勾才可上线|上线清单]]大圆专项），不默认平移。

## 七、给管理员的一句话

管大圆的预期要摆正：**它现在是"个人工具长在了企业环境里"**——企业侧只有保存期限和间接权限两个硬抓手，真正的运行管理靠"申报 + 巡检 + 红线禁令"这套轻制度。等企微给大圆出企业级管控（关注版本更新，[[05-公司管理流程/07-版本与变更-双端升级跟着官方走|版本与变更]]），再把制度收缩回硬控制。
