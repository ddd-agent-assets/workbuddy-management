# 5 其他连接器：邮箱、文档、会议、TAPD，按卡片授权

**结论**：WorkBuddy 的连接器是"一个服务一张卡片、各自授权、各管各的"——**接哪个授权哪个，用完解绑**。企微连接器（session 直连）见[[01-WorkBuddy维度/04-session直连企微连接器-会话内编辑文档表格|WorkBuddy篇：session直连连接器]]，本篇讲其余卡片式连接器。

## 一、连接器清单（2026-09 社区核查，以 App 内显示为准）

| 连接器 | 能干什么 | 授权方式 |
| :--- | :--- | :--- |
| **QQ 邮箱** | 读近一个月收件箱、发邮件、删邮件（删除为可选授权） | QQ 邮箱 App（≥7.1.5 / 鸿蒙 ≥0.2.9）扫码 |
| **腾讯文档** | 搜索、预览、引用段落、**回写修改**（2026-04 深度打通，5.5.0 编辑增强） | 授权页微信/手机号登录 |
| **腾讯乐享** | 搜索知识库、查询内容、协助创建管理 | 卡片式授权 |
| **腾讯会议** | 拉会议纪要、提取决议待办（**需开启录音转文字**） | 卡片式授权 |
| **TAPD** | 读需求、缺陷、迭代数据，汇总项目进度 | 卡片式授权 |
| **腾讯网盘（微云）** | 通过已授权连接器访问网盘文件 | 卡片式授权 |
| **自定义连接器** | 通过 MCP 协议自接其他系统（技术向，找 IT） | mcp.json / 配置页 |

> 连接器是技能的特殊形态（MCP + CLI 或 Skill + CLI）。**不同服务的登录、授权和工具范围机制不同**，不能把企微的长连接机制套到所有连接器上。

## 二、授权五步（通用）

1. 左侧栏 **专家·技能·连接器 → 连接器** 页签（一级菜单没有就查"更多"）；
2. 目标卡片右侧点 **+ / 添加 / 连接**；
3. 按弹出授权页完成登录（扫码/网页授权）；
4. **逐条读授权范围**：有可选项时只选当前任务需要的（如 QQ 邮箱的"删除邮件"不开）；某项权限不能独立关闭又不能接受 → **取消连接**，改用练习附件；
5. 回到 WorkBuddy 确认卡片出现绿点/"已连接"，**再发一个小请求验证**（看到图标 ≠ 能用，5.6.2 起授权完成才显示图标）。

## 三、生命周期管理（写进习惯）

| 时机 | 动作 |
| :--- | :--- |
| 每月 | 检查一次"已连接"列表，不用的**解绑** |
| 任务结束 | 会话内取消启用（+ → 连接器），与解绑是**两个不同操作** |
| 断开/失效 | 卡片点"重新连接/刷新授权"；网络中断恢复后会自动重连（5.6.0 改善探活），别删配置 |
| 离职/换岗 | **敏感账号连接器必断**，见[[05-公司管理流程/08-调岗离职交接-先停写再验证七天收权|管理流程：交接]] |

## 四、万一出事了（应急四步）

1. **停**：立即停止相关任务；
2. **断**：连接器管理页解绑并核对状态；
3. **救**：去外部平台（邮箱/文档）查回收站、版本历史恢复；
4. **核**：重新使用前核对可选权限与练习结果。

记住：**解绑不会撤回已发出的内容**——发错的消息/邮件要另行处理。
