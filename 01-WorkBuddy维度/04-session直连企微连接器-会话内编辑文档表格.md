# 4 session 直连企微连接器：会话内直接编辑文档、表格和 PPT

**结论**：WorkBuddy 客户端的会话（session）里开启**企微连接器**后，AI 能在会话内**直接引用微盘文件，读取、编辑在线文档、表格和 PPT**，还能调用日程、会议、待办、邮件数据——不用下载、上传、来回切换。这类文档和业务数据操作通过 **wecom-unified（CLI）连接能力**完成；它和"大圆"是**两条分工明确的执行路径**（大圆管聊天消息，见[[02-大圆维度/01-大圆联动-消息的读检索发由大圆承接|大圆篇：大圆联动]]）。

## 一、两条执行路径，一张表分清

| 路径 | 管什么 | 例子 |
| :--- | :--- | :--- |
| **大圆**（企微 AI 助理联动） | 聊天**消息**的读取、检索、发送 | 总结群聊、检索某群某时段记录、代发消息（需本人确认） |
| **wecom-unified**（session 直连连接器） | **文档、表格、PPT、微盘、日程、会议、待办、邮件**等业务数据 | 会话内读纪要生成智能文档、改表格、上传产物到微盘 |

> 记不住就记一句话：**"聊天的走大圆，干活的走 wecom-unified。"** 两边授权各自独立，一边通了不代表另一边也通。

## 二、会话内怎么开（四步）

1. **建会话**：WorkBuddy 客户端新建任务/会话（用企微账号登录，见[[01-WorkBuddy维度/03-账号与计费-企微账号不互通|WorkBuddy篇：账号与计费]]）；
2. **开连接器**：输入框左下角 **+ → 连接器**，开启本次要用的（企微/腾讯文档/微盘等）；不用时在同一面板**取消启用**；
3. **首次授权**：按弹出的授权页完成登录/授权；执行中需要外部服务时，输入框上方会弹**连接引导卡片**，点"连接"后当前任务自动继续，不必重建任务；
4. **小请求验证**：先让 AI 读一个你有权限的小文档，核对调用记录确实来自该连接器。

> ⚠️ **开关、服务授权、实际调用是三件事，分别核对**，不能只凭图标绿点判断（5.6.0/5.6.2 修复过"关了仍显示开、关闭后对话残留工具"的问题）。切换账号后要重开目录核对当前账号可见的连接器——个人账号与企业账号的清单可能不同。

## 三、会话内编辑文档表格：能做什么

| 动作 | 会话内怎么说 | 注意 |
| :--- | :--- | :--- |
| **读** | "读取《船期ETA表》本月数据，汇总异常" | 读别人的表要授权 + 发链接（企微老规矩） |
| **改（追加）** | "在这份文档末尾追加一段……，其他内容不要动" | 编辑前保存版本或副本；完成后打开原文核对差异 |
| **建** | "把这份会议纪要整理成新的智能文档，存到企微" | AI 自建的新文档随便写——**写只写自建** |
| **PPT** | "按这个模板改第 3 页的图表" | 大改动先复制副本再让 AI 动手 |
| **微盘** | "把生成的报表上传到微盘 xx 目录" | 任务产物一键归档 |
| **日程/会议/待办** | "查我本周会议，提取待办" | 会议内容读取需**本人授权** |

**实测参考**（智东西 2026-10-14）：读取微盘里的会议纪要 → 会话内生成企微智能文档保存，全程不用离开 WorkBuddy；未读邮件三类归纳（需处理/值得关注/其他）同样在会话内完成。

## 四、六条边界，别踩

1. **企微文档硬边界原样生效**：AI/机器人写不了员工建的旧表旧文档，只能写自己新建的；读要本人授权（官方写明授权有效期 **7 天**，到期重新扫码）；智能表格单独授权上限 20 人、权限只有三档（详见[[04-通用规则/02-红线速查-批了也没用别硬闯|通用规则：红线速查]]）；
2. **"已连接" ≠ 不会误删误改**：AI 改错的可能一直存在，重要文档**编辑前存版本/副本**，改完对照差异；
3. **取消启用 ≠ 解除授权**：会话内取消启用只影响本次任务，解除服务授权要回连接器管理页**解绑**；解绑也**不会撤回**已发出的内容；
4. **token 会过期**：长时间不用或对方平台 token 过期会断开，回卡片点"重新连接/刷新授权"；网络中断恢复后会自动重连（5.6.0 改善探活），**不要为一次中断删配置**；
5. **消耗的是 AI 处理，不是读写**：连接器自身读写不耗积分，AI 理解汇总生成才耗（见[[05-公司管理流程/06-用量与积分-额度加购限额三件事|管理流程：用量与积分]]）；
6. **团队共享文档**：能否读取以你账号的实际权限和连接器支持范围为准，"我能打开"不代表"AI 能读"。

## 五、给 IT 的一句话

自定义连接器走 MCP 协议（连接器管理页右上角"自定义连接器"，5.6.0 起支持直接编辑 `mcp.json`）；改前备份、改后小请求验证；**凭证只填配置界面，不贴进对话、不入库**。会话加载 MCP 时展开"正在连接 MCP 服务"可看已连接数/总数。
