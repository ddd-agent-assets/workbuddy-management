# 1 WorkBuddy 是什么：客户端、会话与全家桶

> 本篇讲**角色一：WorkBuddy 本身**。三角色关系先看 [[00-总览/01-三个角色-WorkBuddy大圆企微bot是什么关系|总览：三个角色]]；它在企微里的形态（分身、大圆）在另外两个维度目录。

**给所有部门的一句话**：WorkBuddy 是腾讯的 AI 办公工作台，**主场是它自己的客户端**——用企微账号登录后，一个**会话（session）**里可以调专家/专家团、技能、知识库、自动化，并通过**连接器**伸进企微和腾讯生态（会话内直接编辑企微文档表格是最重要的一个，单独成篇见 [[01-WorkBuddy维度/04-session直连企微连接器-会话内编辑文档表格|04篇]]）。

## 一、客户端与会话是什么

| 概念 | 一句话 |
| :--- | :--- |
| **客户端** | WorkBuddy 桌面 App（另有移动 App、微信/企微助理通道、小程序等入口）；工作场景**用企微账号登录** |
| **会话（session）** | 你和 AI 的一段连续对话+任务上下文；输入框左下角 **+ → 连接器** 可给本次会话开启外部能力 |
| **双端同步** | 企微里的 WorkBuddy 机器人与客户端会话**上下文双端同步**，切换不用重复交代 |

## 二、会话里能调什么（能力全家桶）

| 能力 | 能做什么 | 典型场景 |
| :--- | :--- | :--- |
| **专家 / 专家团** | 角色化 AI 协同，团长自动拆解任务并行执行 | 周报生成、深度调研 |
| **技能** | 可复用的任务方法与工具（技能市场可装） | 固定格式产出 |
| **知识库** | 喂资料给 AI 当依据，支持邀请企微成员协作 | 客服知识库问答 |
| **自动化** | 定时任务到点就跑，结果推送到企微 bot/小程序 | 每天 9 点邮件简报 |
| **连接器** | 伸进外部服务：**企微（session 直连，04篇）**、QQ 邮箱、腾讯文档、会议、TAPD、微云、自定义 MCP | 会话内改表格、读会议纪要 |
| **Coding Mode** | 偶尔写代码、做小工具 | 小脚本、demo |

> 连接器读写**不消耗积分**，AI 理解/汇总/生成才消耗——预算规则见 [[05-公司管理流程/06-用量与积分-额度加购限额三件事|管理流程：用量与积分]]。

## 三、三条边界（三角色通用，先记牢）

1. **读要本人授权**：会议内容、邮件等敏感操作的读取需员工**本人授权**，管理员无法绕过；
2. **写只写自建**：AI 写不了员工建的旧表旧文档，只能写自己新建的——"共享给它"也走不通；
3. **代发必须本人确认**：以你名义发消息，发送前必须逐条确认接收对象和内容。

完整 16 条红线见 [[04-通用规则/02-红线速查-批了也没用别硬闯|通用规则：红线速查]]；授权全景见 [[04-通用规则/01-授权边界-敏感操作本人授权代发要确认|通用规则：授权边界]]。

## 四、各部门速查

| 部门 | 优先用 | 现在就能受益的事 |
| :--- | :--- | :--- |
| 客服 | 专家团 + 知识库 + session 直连 | 群内问答、异常整理、会话内维护台账 |
| 业务/销售 | 自动化 + session 直连 | 询盘登记、客户邮件整理、周报表格 |
| 行政 | 自动化 + 大圆联动 | 会议纪要、通知定时搬运、日程会议室 |
| IT/管理员 | 连接器（自定义 MCP）+ 后台 | 内部系统接入、席位与连接器管理 |
| 管理层 | 侧边栏 + 大圆 | 轻量问答、每天消息邮件简报 |
