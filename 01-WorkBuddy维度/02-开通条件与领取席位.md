# 2 开通条件与领取席位：先过三道门，再走两条路

**结论**：用 WorkBuddy 要占一个**席位**。之前先过**三道门**——企微企业已认证、企微桌面端 ≥ 5.0.12、WorkBuddy ≥ 5.8.0；然后走**两条路**——有试用名额自己在侧边栏领（先到先得），没名额点"申请使用"发卡片给管理员，管理员在管理后台购买席位再分配。**领了席位才谈得上用，后台按席位算钱，没有绕过席位的免费通道。**

## 一、三道门（缺一道都看不到入口）

| 条件 | 要求 | 不满足会怎样 | 去哪确认/处理 |
| :--- | :--- | :--- | :--- |
| 企业认证 | 企微企业**已认证**（试用名额仅对已认证企业开放） | 领不了试用席位 | 问管理员（DIC IT）认证状态 |
| 企微版本 | 桌面客户端 **≥ 5.0.12** | 侧边栏没有"智能机器人"入口 | 企微客户端检查更新 |
| WorkBuddy 版本 | **≥ 5.8.0**（企微账号登录、session 直连等能力从此版起） | 客户端连不上企微数据 | WorkBuddy App 内更新 |

> 给 IT 的一句话：部分功能受**企业认证、客户端版本和授权范围**三方限制，有些操作必须回企微客户端或管理后台完成——报"功能不见了"先查这三样，别当故障报修。

## 二、两条路

| 路径 | 谁做 | 步骤 | 频率 |
| :--- | :--- | :--- | :--- |
| **路径 A：领试用** | 员工本人 | 企微**桌面端** → 侧边栏 → 智能机器人 → 打开 WorkBuddy 主页 → 点**"领取并使用"** | 每人一次 |
| **路径 B：申请席位** | 员工发起，管理员批 | 同一入口看到"无席位"时点**"申请使用"** → 请求卡片发给管理员 → 管理员进管理后台**购买席位并分配** | 每人一次；换人要换席位 |

> ⚠️ 试用名额**数量有限、先到先得、仅已认证企业**。没抢到不是被区别对待，走路径 B 就好。

## 三、领取成功后，能干什么

1. **企微里直接用**：WorkBuddy 出现在企微聊天/通讯录中，可对话派任务，连接 WorkBuddy 云端助手处理；
2. **想用完整功能**：下载最新版 WorkBuddy 客户端，**用企业微信身份登录**，配置模型选择、技能/工具等高级设置（账号注意事项见 [[01-WorkBuddy维度/03-账号与计费-企微账号不互通|03篇：账号与计费]]）；
3. 会话内直连企微连接器、编辑文档表格：[[01-WorkBuddy维度/04-session直连企微连接器-会话内编辑文档表格|04篇：session直连连接器]]。

## 四、常见卡点

- **侧边栏没有 WorkBuddy 入口** → 企微桌面端版本 < 5.0.12，先升级；手机端暂非领取入口，用电脑领；
- **点领取提示无名额** → 名额发完了，走路径 B 申请；
- **申请卡片发出去没下文** → 采购与分配见 [[05-公司管理流程/01-管理员两个后台-企微管理端加WorkBuddy后台|管理流程：管理员后台]]，催管理员别催 IT 工单；
- **领取后客户端登录显示"什么都没有"** → 确认登录用的是**企微账号**且企业已开通；账号数据互通问题见 03 篇。
