# 3 账号与计费：企微账号不互通，席位加积分两笔钱

**结论**：用 WorkBuddy 前先懂两件事——**账号**：企微账号登录的 WorkBuddy 与原有个人账号**数据和使用状态不互通**；**钱**：企业用 = **席位订阅（刊例 198 元/人/月起）+ 积分（Credits）加油包**，积分按 AI 实际处理量消耗。这篇文章的数字都是**快照**，采购前以当日订单页为准。

## 一、账号三层 + 一个大坑

| 层 | 给谁 | 核心特征 |
| :--- | :--- | :--- |
| 个人版 | 个人试用、轻度使用 | 单账号订阅制，与 CodeBuddy 共享积分池 |
| 企业 SaaS 版 | 团队、公司（我们现在的选择） | 按席位计费、集中管理、团队积分共享 |
| 专有云企业版 | 大企业、强合规 | 私有部署、数据驻留可控、100 席起购 |

**⚠️ 大坑：企微账号与原有账号不互通。** 用企微账号登录 WorkBuddy 客户端后，**原有账号的积分、历史会话、订阅状态不会带过来**（智东西 2026-10-14 实测确认）。所以公司规定：**工作场景一律用企微账号登录**，别把公司业务沉淀在个人账号里——人走了个人账号一注销，资产全丢。

## 二、企业侧的钱：席位 + 加油包

**席位（企微渠道刊例，官方购买与计费说明 doc_id 21747）：**

| 项目 | 规矩 |
| :--- | :--- |
| 席位价 | **198 元/人/月**，最低 1 席起购 |
| 新购时长 | 1-11 个月或 1-3 年 |
| 增购席位 | 时长与现有席位**最新到期日对齐** |
| 续费 | 席位数量**不可调整**，只能按当前席位数续；总有效期不超过 3 年 |
| 支付 | 在线支付或公司银行转账 |

**Credits 加油包（有效期 6 个月，超期作废）：**

| 算力额度 | 价格（企微渠道） |
| :--- | :--- |
| 2,000 Credits | 100 元 |
| 10,000 Credits | 480 元 |
| 50,000 Credits | 2,375 元 |

**WorkBuddy 直购渠道另有档位**（教程 2026-09-14 快照）：企业旗舰版 SaaS 198 元/人/月（年付 2,376 元，含 2,000 积分/人/月团队共享）；企业加量包五档（2,000/100 元、5,000/245 元、10,000/480 元、50,000/2,375 元、200,000/9,200 元）；专有云企业专享版 316 元/人/月、**100 席起购**。两渠道价格体系可能不同步，**下单前以订单页或书面报价为准**。

## 三、积分机制（必懂）

1. **什么消耗积分**：连接器自身的读写**不**消耗积分；**AI 理解、汇总、生成**消耗积分。不能按"读邮件便宜、批量处理贵"推算固定价格，先小材料试跑再查用量；
2. **消耗优先级**：免费体验额度 → 赠送积分（按到期顺序）→ 付费积分；
3. **在哪看**：客户端"设置 → 订阅和用量"（个人视角）；管理后台"用量/用量管理"（管理员视角，见[[05-公司管理流程/06-用量与积分-额度加购限额三件事|管理流程：用量与积分]]）；
4. **预算提醒**：官方"加赠积分"是限时活动，**别按加赠后的数字做长期预算**；加油包 6 个月有效期，按季度规划采购。

## 四、给管理层的采购建议

- 先领试用名额跑通场景，再按实际用量决定席位数与加油包节奏（种子用户策略见[[06-提议与附录/01-提议-组织SOP|组织SOP提议]]）；
- 强合规、数据必须留在自有环境 → 才考虑专有云（316 元/人/月、100 席起，需腾讯销售配合实施）；
- 积分池团队共享，**高频自动化任务（定时汇总类）是消耗大户**，上线前先估量（见[[05-公司管理流程/06-用量与积分-额度加购限额三件事|管理流程：用量与积分]]）。
