# 2 版本基准：本库基于什么版本，怎么判断它过期了

**结论**：本库（v2.0）的规则、界面路径、价格数字，全部基于 **企业微信桌面端 5.0.12 + WorkBuddy 5.8.0**（2026-10-14 联合发布的深度融合版），核查日期 **2026-11-13**。企微和 WorkBuddy 任何一端大版本更新后，先过一遍本篇的"三问"，再决定哪些篇章要复核。

## 一、基准版本一览

| 项 | 基准值 | 说明 |
| :--- | :--- | :--- |
| 库版本 | **v2.0**（2026-11-13） | 结构大改升主号，内容修订升次号 |
| 企业微信 | **桌面端 5.0.12** | 融合能力（通讯录机器人、侧边栏领取、频道）从此版起 |
| WorkBuddy | **5.8.0** | 企微账号登录、双端同步、session 直连企微从此版起 |
| 依据的官方文档 | 企微帮助 doc_id 21743-21747；开发者文档 path/101468 等 | 清单见 [[06-提议与附录/03-附录-证据与信源\|附录]] |
| 核查日期 | 2026-11-13 | 价格、灰度状态以当日为准 |

## 二、版本时间线（谁带来了什么）

| 时间 | 版本 | 带来了什么 |
| :--- | :--- | :--- |
| 2026-08-18 | 企微 5.0.10 | CLI/MCP 全面开放、不限企业规模（**前库的基准版本**） |

| 2026-04 → 08 | WorkBuddy 5.5.0/5.5.5/5.5.6 | 腾讯文档编辑增强；转发记录自动解析；助理功能 |

| **2026-10-14** | **企微 5.0.12 + WorkBuddy 5.8.0** | **深度融合：三角色成型（本库基准）** |

更细的版本对照与升级管理流程见 [[05-公司管理流程/07-版本与变更-双端升级跟着官方走|管理流程：版本与变更]]。

## 三、怎么判断本库过期了（三问）

1. **企微桌面端大版本更新了吗？**（当前 5.0.12 → 更高）侧边栏入口、机器人管理、频道灰度最可能变；
2. **WorkBuddy 大版本更新了吗？**（当前 5.8.0 → 更高）连接器清单、会话内编辑能力、计费最可能变；
3. **官方帮助文档改了吗？** doc_id 21743-21747 和 [[04-通用规则/02-红线速查-批了也没用别硬闯|红线速查]] 对照一遍。

三问任何一个命中"是"：先复核[[04-通用规则/02-红线速查-批了也没用别硬闯|红线速查]]和[[01-WorkBuddy维度/04-session直连企微连接器-会话内编辑文档表格|session直连连接器]]，再把本篇基准表更新为新版本号，README 顶部同步改。

## 四、各篇章的时效性标注

- **易变信息**（价格、加赠、灰度）：正文都标了"快照日期"，以当日订单页/官方帮助为准——本库数字只在标注日期当天保证准确；
- **稳定信息**（三条边界、授权机制、建号审批流程）：随大版本复核，平时不动；
- **待核实清单**：官方文档与实测矛盾的地方（如授权 7 天有效期）集中在[[06-提议与附录/03-附录-证据与信源|附录]]第五节，有新结论先改那里。
