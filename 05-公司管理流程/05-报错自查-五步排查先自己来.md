# 5 报错自查：五步排查，先自己来

**结论**：WorkBuddy 场景出问题，**先按这五步自查，大多数情况不用惊动 IT**；五步全对还报错，再按"报修三要素"上报。前库的"无权限四步"已并入本表第二步。

## 五步排查（按顺序）

| 步 | 查什么 | 怎么查 | 常见命中 |
| :--- | :--- | :--- | :--- |
| **1. 版本** | 双端版本达标吗 | 企微桌面端 ≥ 5.0.12、WorkBuddy ≥ 5.8.0（融合能力）；入口看不到功能先查版本 | 侧边栏没有入口、通讯录没有机器人、功能"消失" |
| **2. 授权** | 该做的授权做了吗 | ①扫码授权做了吗（本人做，不能代办）②文档链接发过了吗（大企业必做）③权限开关开了吗（"能读文档"和"能查通讯录"是两个独立开关，"去开通"链接要创建者本人点）④连接器授权过了吗（卡片绿点 + 小请求验证） | 报"无权限"的绝大多数 |
| **3. 席位与范围** | 席位分到了吗、在可见范围吗 | 管理后台"允许的成员"里有没有你；机器人可见范围含不含你的群 | 企微里看不到 WorkBuddy、用着用着提示无席位 |
| **4. 通道与状态** | 连接器/通知通道状态对吗 | 连接器卡片是否"已连接"（token 过期点重新连接）；定时任务是否"已启用"、电脑网络 App 是否在线（本地任务要在线才跑）；通知通道是否断开（**解绑后开关不会自动关**，红点提示要重绑） | 推送没收到、任务没跑、连接器读不到 |
| **5. 量与积分** | 额度还有吗 | 读表每日上限超了吗（超了当天停、次日恢复）；积分用完了吗（设置→订阅和用量）；管理端限额被调低了吗 | 任务跑不动、突然中断 |

## 特殊情况：五步全对还报错

- **腾讯授权同步故障**（2026-08 下旬出现过）：可先让当事人重新扫码一次"刷"权限；受影响的通常是"搜文档""查通讯录"，**读指定文档不受影响（发链接即可）**；
- **授权 7 天有效期矛盾**：官方文档写"授权有效期为 7 天"，与实测"长期有效"不一致——用了几天突然报无权限，**先重新扫码授权**，记录发生时间反馈管理员；
- **AI 改错文档**：立即停任务 → 连接器解绑 → 外部平台查版本历史恢复 → 核对后重启（应急四步详见[[01-WorkBuddy维度/05-其他连接器-邮箱文档会议TAPD按卡片授权|WorkBuddy篇：其他连接器]]）。

## 报修三要素

仍解决不了再报管理员/IT，报时附上：**哪个场景/哪台机器人、哪张表或哪个连接器、五步自查的结果**。
