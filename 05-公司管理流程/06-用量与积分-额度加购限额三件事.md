# 6 用量与积分：额度、加购、限额三件事

**结论**：WorkBuddy 的用量管理就三件事——**看**（知道花到哪了）、**管**（给大户设限额）、**加**（不够了买加油包）。前库"读表日上限 + 超大表拆分"两条老量限继续有效，本篇补上积分这一新维度。

## 一、看：两处入口

| 谁看 | 在哪看 | 看什么 |
| :--- | :--- | :--- |
| 个人 | WorkBuddy 设置 → **订阅和用量**（5.4.7 起独立页） | 套餐概览、分类积分、资源包明细、自动续费管理 |
| 管理员 | 企微管理后台 → WorkBuddy → **用量 / 用量管理** | 本周期公司总用户数、配额消耗、加购包状态、**个人明细用量** |

## 二、管：限额与优先级

- **管理员限额**：管理后台可按成员/部门批量调整限额，**调整后成员本周期内不可超额使用**——高频自动化大户建议提前设限额，防止积分池被一个任务烧干；
- **积分消耗优先级**：免费体验额度 → 赠送积分（按到期顺序）→ 付费积分。赠送积分多为限时活动，**别按加赠后的数字做长期预算**；
- **什么耗积分**：连接器自身读写**不**耗；**AI 理解、汇总、生成**耗。专家团并行、长文档分析、深度调研是消耗大户。

## 三、加：加油包（Credits）

| 事项 | 规矩 |
| :--- | :--- |
| 档位（企微渠道） | 2,000/100 元、10,000/480 元、50,000/2,375 元（大包单价更低） |
| **有效期** | **6 个月**，超期作废——按季度规划，别囤货 |
| 购买入口 | 管理后台 → WorkBuddy → 购买/管理 → 增值包（价格快照见[[01-WorkBuddy维度/03-账号与计费-企微账号不互通|WorkBuddy篇：账号与计费]]） |

## 四、两条老量限（沿用前库，继续有效）

1. **机器人每天读表有总次数上限**：超了当天读写全停，第二天自动恢复。日常询盘登记远够用；一次性补大量历史数据，**分几天做**；
2. **超大表分表存放**：约 5 万字量级的大表曾有读取中断记录（工具升级后已解决），历史很久的大台账仍建议**按年或季度拆分**。

## 五、月度例行（管理员）

- 看一次全员用量排行，找异常大户；
- 核对加购包剩余额度与到期时间（6 个月有效期）；
- 台账"额度"列同步更新（[[05-公司管理流程/03-登记台账-在线表格|管理流程：登记台账]]）。
