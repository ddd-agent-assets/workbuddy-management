# 1 管理控制点全景：产品自带的硬控制有哪些（两个后台 + 运行侧看板）

**结论**：管 WorkBuddy 时代的 AI 办公，**先用手里的硬控制，再用制度补位**。产品自带的控制点分三层：**①企微管理后台**（管人和钱：席位、权限、用量限额）；**②WorkBuddy 企业版管理后台**（管资产和安全：成员授权、审计日志、连接器公共授权、客户端安全）；**③运行侧看板**（管日常：定时任务、最近任务、连接器状态——在产品界面里，不在后台里）。**大圆没有企业后台**，是唯一例外，只能靠"①间接限制 + ③个人侧看板巡检"补位（专门一篇见 [[02-大圆维度/03-大圆怎么管-范围最小敏感群禁用月审|大圆篇：怎么管]]）。

## 一、总表：五个管理面，哪些是硬控制

| 管理面 | 入口 | 硬控制（关了就真关） | 管什么 | 谁操作 |
| :--- | :--- | :--- | :--- | :--- |
| **① 企微管理后台** | 企微管理后台 → 智能化专区 → 智能机器人 → 机器人管理 → WorkBuddy | 席位分配、企业应用权限、用量限额 | 人和钱 | 管理员 |
| **② WorkBuddy 企业后台** | 从①跳转，或独立登录（腾讯云 WorkBuddy Enterprise 控制台） | 成员授权、订阅、客户端安全策略、连接器公共授权 | 资产和安全 | 管理员/IT |
| **③ WorkBuddy 运行侧看板** | 客户端：自动化任务页、连接器管理页、订阅和用量页 | 定时任务启停、连接器解绑 | 日常运行 | 负责人自查 |
| **④ 大圆个人侧看板** | 企微智能助理首页：定时任务 / 最近任务 / 数据隐私与安全 | 定时任务停删、任务与云端产物删除、隐私开关 | 个人 AI 的运行痕迹 | 每个员工（管理员无后台，只能巡检台账） |
| **⑤ 企微后台-云端保存期限** | 企微管理后台（大圆相关设置） | 任务输入与执行结果的云端保存期限 | 大圆数据留存 | 管理员 |

> **务实的第一原则：能用①②关掉的，不要靠员工自觉；①②没有开关的，才进入台账和巡检。**

## 二、①企微管理后台：人和钱（doc_id 21746）

| 配置项 | 硬控制 | 操作要点 |
| :--- | :--- | :--- |
| **购买与管理** | 席位订单 | 席位订单、已用/已分配席位、有效期；试用未过期点购买进**增购**页 |
| **允许的成员** | **席位分配——没分到就用不了** | 人员变动先改这里；离职回收席位（[[05-公司管理流程/08-调岗离职交接-先停写再验证七天收权\|交接篇]]） |
| **允许的权限** | **企业应用权限——不授权，成员就用不了该能力** | 最小化开放，别开全家桶；这是限制"大圆联动能用 WorkBuddy 做什么"的**间接总闸** |
| **用量** | 可视 | 本周期总用户数、配额消耗、加购包状态、**个人明细** |
| **用量管理** | **限额——调整后本周期内不可超额** | 按周期/状态筛选，按成员/部门搜索，可**批量调整**；高频自动化大户必设 |
| **服务商** | — | 采购、实施问题入口 |

## 三、②WorkBuddy 企业版管理后台：资产和安全（腾讯云 product/1316 + doc_id 21746）

| 模块 | 能做什么 | 要点 |
| :--- | :--- | :--- |
| **成员授权 > 成员与部门** | 浏览、单个/批量授权、取消授权、移除成员 | 数据来自**腾讯统一身份（OneID）**：增删改人员去 OneID 做，WorkBuddy 后台只管授权；OneID 是**全量同步**，会覆盖 WorkBuddy 侧改动；**授权数量受席位数限制** |
| **成员审核** | 成员加入审核 | 控制谁能进企业空间 |
| **组织架构同步** | 从**企微一键同步**组织架构 | 千人企业"手动录入一周，同步十分钟"；同步不自动授权，授权仍要点 |
| **订阅管理** | 订阅席位、扩容 | 与①的购买管理对账用 |
| **客户端安全** | 安全策略下发（如 Windows 路径规则） | 企业下发含 `%USERPROFILE%` 的路径规则 5.6.0 起生效；**IT 在测试环境验收后再下发** |
| **企业智能体 / 模型 / 技能 / 连接器** | 企业级配置与开放范围 | **连接器支持管理员配置的公共授权**（公共票据被成员共同使用）与成员个人授权并存——先确认服务账号用途和成员范围再开公共授权 |
| **安全与风控策略** | 限制 AI 访问高敏感信息、界定数据流转路径 | 大圆联动场景的兜底约束之一 |
| **操作日志与聊天记录** | **审计：谁在何时用 AI 做了什么、花了多少** | "统一治理审计"是企业版核心卖点（管人、管 AI、管钱、管 IP）；**实际可见范围与保留期限以所购版本合同为准，逐项确认** |
| **角色边界隔离** | 按角色划分权限范围 | 管理员/普通成员/审计员分权 |

> ⚠️ **"企业版"三个字不能自证每一项都有**——上表逐项对照所购版本文档/合同确认，再写进管理规程（WB-10 教程的采购核对原则）。

## 四、③运行侧看板：日常管理抓手（在产品界面，不在后台）

| 看板 | 在哪 | 能做什么 |
| :--- | :--- | :--- |
| **自动化任务页** | WorkBuddy 客户端 → 自动化 | 任务列表、**启用/停用**、运行记录、通知通道绑定状态——定时任务的"总开关看板"，交接停写就停在这里 |
| **连接器管理页** | 专家·技能·连接器 → 连接器 | 已连接清单、解绑、重新连接——月检（[[01-WorkBuddy维度/05-其他连接器-邮箱文档会议TAPD按卡片授权\|连接器篇]]）的操作面 |
| **订阅和用量页** | 设置 → 订阅和用量 | 个人套餐、分类积分、资源包明细 |
| **大圆-定时任务** | 企微智能助理首页 → 定时任务 | **立即运行 / 暂停 / 删除**——大圆的定时任务在这里管（个人侧，详见 [[02-大圆维度/03-大圆怎么管-范围最小敏感群禁用月审\|大圆篇：怎么管]]） |
| **大圆-最近任务** | 智能助理 → 最近任务列表 | 查历史任务、**删除任务（含云端保存的文件产物）** |

## 五、管理组合策略（基于当前版本产品的现实）

| 目标 | 用哪个控制点 | 性质 |
| :--- | :--- | :--- |
| 控制谁能用 | ①席位分配 + ②成员授权 | **硬** |
| 控制能用什么能力 | ①允许的权限 + ②连接器公共授权范围 | **硬** |
| 控制花费 | ①用量限额（超额即停） | **硬** |
| 控制敏感数据 | ②安全风控 + 数据分级场景审批 | 硬 + 制度 |
| 控制定时任务失控 | ③自动化看板停用 + 台账清单 | 半硬（要人去点） |
| 控制大圆 | ⑤保存期限 + ①间接限制 + 台账巡检 | **基本靠制度**（大圆无企业后台） |
| 审计追溯 | ②操作日志（范围以合同为准） | 硬（可用性待合同确认） |

## 六、给管理员的操作顺序建议

1. **先配硬控制**：①席位只分给获批成员 → ①权限最小化 → ①设用量限额 → ②开审计、配客户端安全；
2. **再挂看板**：把③的自动化任务页、连接器页列进**月度巡检清单**（谁的任务在跑、哪些连接器还连着）；
3. **最后补制度**：①②③覆盖不到的（大圆的行为细节、代发确认质量、敏感群），才用台账、清单、培训补位——**制度的量，和产品硬控制的缺口成正比**。
