# 2 上线检查清单：逐项打勾才可上线

**结论**：一个 WorkBuddy 使用场景（或自建机器人）上线前，拿这张清单逐项打勾——**任何一项打不上勾，就不予上线**。勾完再走[[05-公司管理流程/03-登记台账-在线表格|管理流程：登记台账]]。清单在前库七项基础上，新增席位、连接器、授权、定时任务四类 WorkBuddy 检查项。

## 数据与边界（沿用 + 扩展）

- [ ] 要动的数据都定过级，没有敏感、绝密数据违规（分级标准见 [[04-通用规则/03-数据分级-什么数据可以交给AI|通用规则：数据分级]]）
- [ ] AI/机器人只往**自己建的**表/文档写，不碰员工旧表
- [ ] 多人共用的表没有用"下载-上传"方式改；AI 改过的格子加底色
- [ ] 新旧表哪个算数、什么时候切换，白纸黑字定了
- [ ] 会话内编辑的文档表格，**编辑前存版本/副本**的操作已写进使用说明

## 账号与席位（新增）

- [ ] 使用者席位已分配（企微管理后台"允许的成员"里有名字）
- [ ] 工作场景统一**企微账号登录**，无人用个人账号处理公司数据
- [ ] 企业应用权限已按需开启（"允许的权限"最小化，没开全家桶）

## 连接器与授权（新增）

- [ ] 用到的连接器逐一授权完成，**授权范围逐项核对过**（可选项只开当前任务需要的）
- [ ] 敏感操作（会议内容、邮件读取）由**本人**完成授权，无代办
- [ ] 代发消息场景已明确"发送前本人确认"的操作人
- [ ] 自建 API 机器人：发布两轮审批已过、授权三步已走完（[[03-企微bot维度/02-自建API机器人-原有三步流程照走|bot篇：自建API机器人]]）

## 大圆专项（消息类场景必查，风险条目见 [[02-大圆维度/02-大圆风险清单-能读消息能代发十一条要防|大圆篇：风险清单]]）

- [ ] 涉及的群都**不在敏感群清单**里（薪酬/涉密/客户核心资料群禁用 AI 整理）
- [ ] 检索范围约定已写进使用说明：**点名群 + 时间段**，不用"搜所有群"式模糊指令
- [ ] 代发场景已明确确认人，且确认动作**三看**（对象/正文/群）已培训
- [ ] 总结产物标注"内部资料，勿外传"，且只作草稿不作定论

## 自动化与通知（新增）

- [ ] 定时任务已**手动试跑一次**并核对了产物
- [ ] 通知通道（企微 bot / 小程序）已绑定并**实际收到过一次**推送
- [ ] 任务的积分消耗估过一遍（高频自动化是消耗大户，见[[05-公司管理流程/06-用量与积分-额度加购限额三件事|管理流程：用量与积分]]）

## 范围与登记（沿用）

- [ ] 机器人/智能体只对实际使用的群、频道和同事开放
- [ ] 文档管理员只有机器人和搭建者本人，没有再授权给别人
- [ ] 台账登记完成（含负责人与交接人），配置/脚本已存公司 GitHub 私有仓库（**凭证不入库**）
