# 7 版本与变更：双端升级跟着官方走

**结论**：WorkBuddy 是"双端产品"——**企微客户端和 WorkBuddy 客户端要一起升**，融合能力（通讯录机器人、大圆联动、session 直连连接器）两头版本都要达标。公司定一条规矩：**双端大版本发布后一周内，管理员先验证、种子用户先试、全员再跟，同时复核红线篇是否失效**。

## 一、双端版本对照（速查）

| 能力 | 企微版本 | WorkBuddy 版本 |
| :--- | :--- | :--- |
| CLI/MCP 全面开放（自建 bot 时代开始） | 5.0.10（2026-08-18） | — |
| 深度融合：通讯录机器人、侧边栏领取、大圆联动、session 直连连接器、双端同步 | **≥ 5.0.12** | **≥ 5.8.0**（2026-10-14 起） |
| 频道（灰度） | 5.0.12+（灰度放量中） | — |

## 二、WorkBuddy 近期版本带来了什么（升级动机一览）

| 版本 | 带来了什么 |
| :--- | :--- |
| 5.5.0 | 腾讯文档连接器编辑能力增强 |
| 5.5.5 | 企微转发聊天记录自动解析（文档/微盘/日程/待办/会议/智能纪要）；系统分享入口转发 |

## 三、升级规矩（公司约定）

1. **先读更新公告**：App 内更新公告（新功能、新连接器、新专家）管理员必读；
2. **管理员先验证**：新版本发布后，管理员在测试配置 + 非敏感练习目录验证一遍（含连接器授权、代发确认、定时任务推送三条主链路）；
3. **种子用户先试**：3-5 个种子用户试用一周，攒问题；
4. **复核红线**：大版本后优先复核[[04-通用规则/02-红线速查-批了也没用别硬闯|通用规则：红线速查]]——平台红线会随版本变化（如授权 7 天问题、20 人上限、频道全量）；
5. **全员跟升**：IT 推送升级通知，明确"不升级会丢哪些功能"。

## 四、降级与回退

- 客户端一般不提供降级；升级出问题按[[05-公司管理流程/05-报错自查-五步排查先自己来|管理流程：报错自查]]处理，解决不了保留报错截图反馈官方客服；
- **配置回退**：mcp.json 等配置改动前**保留备份**，改后小请求验证；升级不回退配置，配置错误不靠重装掩盖。

## 五、变更登记

- 大版本升级后，台账"使用形态/连接器清单"字段核对一遍（新版本可能新增/下线连接器）；
- 版本时间线更新进[[06-提议与附录/03-附录-证据与信源|附录：证据与信源]]的信源清单。
