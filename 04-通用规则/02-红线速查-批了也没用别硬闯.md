# 2 红线速查：批了也没用，别硬闯

**结论**：下面这些全是平台当前的**固定行为**，审批、管理员配置、换工具都解不了——踩中哪条，直接按"怎么绕"转方案。前七条是企微平台老红线（沿用前库），后九条是 WorkBuddy 融合时代新增。**双端大版本更新后优先复核本篇**（见[[05-公司管理流程/07-版本与变更-双端升级跟着官方走|管理流程：版本与变更]]）。

## 一、企微平台红线（老七条，继续有效）

| 红线 | 怎么绕 |
| :--- | :--- |
| ① AI/机器人写不了别人建的表（共享给它也不行，实测过） | AI 建新表记新数据，旧表挂索引 |
| ② 读别人的表要授权 + 发链接 | 走[[04-通用规则/01-授权边界-敏感操作本人授权代发要确认|通用规则：授权边界]]的授权表 |
| ③ 智能表格最多单独授权 20 人 | 按群/全员设置，或拆表 |
| ④ 智能表格权限只有三档（可看/可改/可管理） | 敏感数据拆表 |
| ⑤ 自建机器人只有建它的人能用 | 一人一个机器人，各自申请 |
| ⑥ "下载-上传"改表会覆盖别人刚改的内容 | 多人共用的表禁用此方式；AI 改过的格子加底色 |
| ⑦ 机器人自建的表，界面上没有"设管理者"入口 | 同事要能改：开"企业内自助加入"；要管理权：找企微超管兜底 |

## 二、WorkBuddy 生态红线（新增九条）

| 红线 | 怎么绕 |
| :--- | :--- |
| ⑧ **WorkBuddy 目前无法直接处理企业审批流程**（实测没有相关技能） | 审批类需求别往 AI 上搬，走企微审批；AI 最多帮你**起草**审批内容 |
| ⑨ **企微账号登录 WorkBuddy 与原有账号数据不互通**（积分、历史、订阅各归各） | 工作场景一律企微账号登录；重要资产别沉淀在个人账号 |
| ⑩ **代发消息必须本人逐次确认**，没有全自动代发 | 接受"起草 + 确认"的节奏，把它当防冒充保险 |
| ⑪ **"已连接"≠不会误删误改** | 会话内编辑文档表格前**存版本或副本**，改完对照差异 |
| ⑫ **会话内"取消启用"连接器 ≠ 解除授权** | 解除授权回连接器管理页解绑；解绑也不撤回已发内容 |
| ⑬ **群内 @ 机器人不默认读取全部群聊** | 材料**随本次消息**发；让 AI 复述收到的范围再开工 |
| ⑭ **通知没收到 ≠ 定时任务没执行** | 先看任务运行记录和本地产物，再查通知通道绑定 |
| ⑮ **频道是灰度功能**，没入口是常态 | 等全量，别当故障报修 |
| ⑯ **本人授权（会议内容/邮件读取）任何管理员都绕不过** | 要用就本人授权，不能用管理手段代授 |

## 三、给技术实施同事的提醒（智能表格既定行为）

新建智能表格自带的默认字段必须先改名再新增字段；写入用**字段标题**做列名、不是字段 ID；单次写入建议 500 行以内；update 类接口不能改字段类型。

## 四、审批分工（老规矩不变）

**审批只解决"读"的授权和内部流程；"写旧表"的诉求直接转技术方案（AI 建新表），别塞进审批空转。** 前车之鉴：DDD 曾把"写旧表"当审批问题推组织发展部门，批完依然写不进。
