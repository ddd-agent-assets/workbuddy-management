# WorkBuddy 管理知识库：三个角色 × 一套管理流程

> **库版本：v2.0（2026-11-13 重构）** · **基准版本：企业微信桌面端 5.0.12 + WorkBuddy 5.8.0**（2026-10-14 深度融合版）
> 版本从哪来、怎么判断本库过期：[[00-总览/02-版本基准-本库基于什么版本|总览：版本基准]]

**这套库管什么**：公司统一使用 AI 办公（WorkBuddy 时代）的全流程知识库，给全公司看——客服、业务、行政、管理层，包括完全没有技术背景的同事。它由前库《企微智能机器人 SOP》（[bot-OA-SOP](https://github.com/ddd-agent-assets/bot-OA-SOP)）演进而来：前库管"怎么搭一个企微机器人"，本库管"WorkBuddy 时代的 AI 办公全家桶"。

## 一、先搞清三个角色（本库的地基）

我们说的"AI 办公"是**三个不同的东西**在配合，本库目录就按这三个角色分：

| 角色 | 一句话 | 主场 |
| :--- | :--- | :--- |
| **WorkBuddy** | 腾讯的 AI 工作台，专家/技能/知识库/自动化/连接器；**文档表格等业务数据操作走 wecom-unified 连接能力** | WorkBuddy 客户端 |
| **大圆** | 企业微信**内置的 AI 助理**；**聊天消息的读取、检索、发送由大圆承接** | 企业微信 |
| **企微机器人** | 企微里的 bot，两种：**WorkBuddy 通讯录机器人**（WorkBuddy 在企微的"分身"）、**自建 API 机器人**（wecom-cli/MCP，前库场景） | 企业微信 |

三者的关系图、六种使用形态怎么归位、"聊天的走大圆、干活的走 wecom-unified"——全部展开见 [[00-总览/01-三个角色-WorkBuddy大圆企微bot是什么关系|总览：三个角色]]。**第一次接触这套库，先读这篇。**

## 四、三句话总结

1. WorkBuddy 时代的 AI 办公 = **WorkBuddy（干活）+ 大圆（消息）+ 企微机器人（入口）** 三角色配合，"聊天的走大圆，干活的走 wecom-unified"；
2. 边界没变：**读要本人授权，写只写 AI 自建，代发必须本人确认**——企微统一规则，任何角色任何工具都绕不开（[[04-通用规则/02-红线速查-批了也没用别硬闯|红线速查]] 16 条）；
3. 新增三件管理事：**席位是钱、连接器是授权、版本是双端**——归 [[05-公司管理流程/01-管理员两个后台-企微管理端加WorkBuddy后台|管理员两个后台]] 管。

## 五、附赠 Skill：workbuddy-guide

[`workbuddy-guide/`](workbuddy-guide/SKILL.md) 是可分发的 AI skill（SKILL.md 标准格式），给 Codex / WorkBuddy 安装后，AI 会指导任何人走通"领席位 → 选角色形态 → 守通用规则 → 登记维护"全流程（组织信息**可配置**，跨组织分发只改配置表）。安装方式：把本仓库链接发给 AI，让它安装 `workbuddy-guide`。

## 六、写作与编号规矩（贡献者看）

- **标题即结论**；不讲技术原理，只讲"能做什么、不能做什么、要找谁、点哪里"；
- **编号**：`00-总览` 先读；`01/02/03` 按角色维度；`04` 通用规则；`05` 公司管理流程；`06` 提议与附录——两套编号（夹内文档从 01 重新起号），`README.md` 与 `workbuddy-guide/` 不编号；
- **事实分层**：官方文档、媒体实测、社区教程、内部实测在[[06-提议与附录/03-附录-证据与信源|附录]]分开列；价格等易变信息一律标注快照日期；
- **改版规矩**：双端大版本更新后，先复核 [[04-通用规则/02-红线速查-批了也没用别硬闯|红线速查]] 与 [[05-公司管理流程/07-版本与变更-双端升级跟着官方走|版本与变更]]，再更新本 README 顶部的基准版本号。
